Privacy policy

Alfred – Briggsy Designs · last updated 16 September 2026

Who this covers

Alfred is a private tool operated by Briggsy Designs (Harry Briggs, sole trader, Gold Coast, Queensland, Australia). It has exactly one user: Harry Briggs. This policy explains how Alfred handles Google user data from his own account.

What data Alfred accesses

  • Gmail — reads messages in Harry Briggs's own mailbox and creates draft messages. Alfred is technically prevented from sending email.
  • Google Drive — reads files in Harry Briggs's own Drive.

How the data is used

Only to run Briggsy Designs' own administration: identifying client enquiries, noticing invoice payments, and preparing drafts for Harry to review. Data is not used for advertising, profiling, training models for third parties, or any purpose beyond running the practice.

Storage and sharing

Data processed by Alfred stays on equipment owned and controlled by Briggsy Designs. Google user data is not sold, rented, or shared with any third party. No other person has access to Alfred.

Google API Services User Data Policy

Alfred's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
